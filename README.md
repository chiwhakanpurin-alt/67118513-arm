# สนามประลองห้องเรียน

เกมยิงมุมมองด้านบนผ่านเว็บเบราว์เซอร์ เล่นพร้อมกันได้สูงสุด 50 คน ใช้ Node.js 20 ขึ้นไป ภาพสนามทหารและพื้นผิววาดด้วย Canvas แบบ 2D ที่แคชลวดลายไว้ เพื่อลดภาระเครื่อง พร้อมแผนที่ย่อและตารางอันดับชื่อผู้เล่นแบบเรียลไทม์

## เริ่มเล่นบน PC

1. ติดตั้ง Node.js 20 หรือใหม่กว่า
2. เปิด PowerShell ในโฟลเดอร์เกม แล้วรัน `npm.cmd install`
3. รัน `npm.cmd start`
4. เปิด `http://localhost:3000` แล้วใส่ชื่อเพื่อสร้างห้อง
5. คัดลอกลิงก์ห้องส่งให้ผู้เล่นคนอื่น จากนั้นกด **เริ่มเกม**

ปุ่มควบคุม: WASD หรือปุ่มลูกศรเพื่อเดิน, เมาส์เพื่อเล็ง และคลิกเพื่อยิง มีอาวุธ 11 แบบให้เก็บ (บางแบบตั้งใจให้ด้อยกว่าปืนเริ่มต้น) ผู้เล่นมี 5 ชีวิต และวงปลอดภัยจะบีบเข้าหาศูนย์กลางภายใน 3 นาที

ระหว่างเกม ตารางด้านขวาเรียงอันดับผู้เล่นที่ยังอยู่ในสนามและแสดงชีวิตที่เหลือ เมื่อผู้เล่นออกจากเกมจะแสดงอันดับที่ได้ และเมื่อจบเกมจะแสดงผลอันดับสุดท้าย

## เล่นกับคนที่อยู่นอกเครือข่ายเดียวกัน

ลิงก์ `localhost` ใช้ได้เฉพาะเครื่องที่เปิดเกมเท่านั้น ต้องนำแอปนี้ไปเผยแพร่บนโฮสต์ที่เข้าถึงได้จากอินเทอร์เน็ต โดยโฮสต์ต้องรองรับ Node.js และ WebSocket จากนั้นแชร์ลิงก์สาธารณะของเว็บไซต์พร้อม `?room=รหัสห้อง` ให้เพื่อน ตัวอย่างเช่น `https://your-game.example/?room=ABCDE` เซิร์ฟเวอร์เดียวกันเป็นตัวกลางให้ผู้เล่นทุกคนเข้าห้องร่วมกัน

ผู้เล่นในห้องเดียวกันต้องเข้าก่อนเริ่มเกม หากต้องการเล่นรอบใหม่ให้สร้างห้องใหม่
